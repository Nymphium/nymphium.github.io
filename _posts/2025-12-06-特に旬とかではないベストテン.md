# はじめに

季節感 なし

脈絡 なし

思い出補正 あり

突然のおすすめ楽曲発表ドラゴンに成ったんで､発表します｡
オールジャンルすぎておすすめ感はない

# 10位 Carbon-based Anatomy - Cynic 

{% twicard "" https://www.youtube.com/watch?v=lY43tiG7jBU&list=OLAK5uy_mbUe15rd5o1Kq2ejtBA6CNAbSLRP4H9Hc %}

狂気と美しさを感じるプログレッシブバンドCynicのアルバム｡
そうベストテンと言いつついきなりアルバムですね｡
『Admist The Coals』の重く複雑な入りから『Box Up My Bones』で突き抜ける感じがたまらん｡
Cynicの他の曲だと『I'm a but wave to …』が狂おしくすき｡

# 9位 目が明く藍色 - サカナクション

{% twicard "" https://www.youtube.com/watch?v=Xcj-SVs31cQ %}

今好きになれる日本のロックバンドってあるんだと思った｡
Queenの『Bohemian Rhapsody』を初めてちゃんと聴いたときと同じ衝撃､いやそれ以上があった｡
日本のロックシーンでこういうのやってくれるんだとか､サカナクションでもキャッチーな『新宝島』などがある中でも依然人気であることに､なんつうかこういう楽曲がちゃんと評価される土壌があることに嬉しさを感じたりとか…｡
『ミュージック』もかなり甲乙つけがたい｡

# 8位 光の螺旋律 - Kukui

爆思い出補正｡ローゼンメイデン2期ED｡
霜月はるかが好きというか､ローゼンメイデンのエンディングで好きになったね｡
アニオリの薔薇水晶とかいう謎キャラがいたが､謎キャラ込みでスループットがあり､曲と合わせて良いですね｡
チェンバロっぽいキーボードと明るくも静謐な旋律がサァ! 翠星石がなあ!!!
2サビ後半の実質テンポアップと間奏のサビと霜月はるかっぽいコーラスで最後まで突き抜けたあとスンッとなる終わりが気持ちいい｡

# 7位 センティフォリア - Ceui

爆思い出補正2｡青い花ED｡
理由はないけど聴いてると涙が出ます｡
アニオリの終わり方もかなり好き｡
あーちゃんは泣き虫なんですなぁ…｡

# 6位 Birdland - Weather Report

{% twicard "" https://www.youtube.com/watch?v=SvhmaNlLgRM %}

実はわたくしベースを弾くのが趣味なんですが､ベースが好きになった一曲｡
だがいきなり最初からハーモニクスでおおよそ普通の(?)ベースらしからぬ高い音が出てくる｡
ベースが好きな曲なら他にもLiquid Tension Experimentの『Acid Rain』とかMr. Bigの『Addicted To That Rush』とかあるが､ベストテンに挙げるならやはりこの曲か｡

# 5位 COSMIC LOVE - 水樹奈々

{% twicard "" https://www.youtube.com/watch?v=-vbKabIRv9U %}

大学受験のあたりで水樹奈々を謎に聴きまくっていたが最も耳に残っている一曲｡
これも思い出補正すか?
サビのメロディの運びが面白い｡
実は『Innocent Starter』もBメロ～サビのつなぎあたりが同じくらい面白い｡

# 4位 True - L'Arc\~en\~Ciel

{% twicard "" https://www.youtube.com/watch?v=-z3zJIA8gxM&list=OLAK5uy_lVGp6u-CXZv6flYYGWzf_W6SRsL9suQLU&index=1 %}

実は2005年くらいまでのラルクがだいたいすきで､中でも思い入れ深いアルバム｡
前アルバム収録の『Vivid Colors』の爽やかさに厚みをかけた『風にきえないで』などバンドとしての洗練も感じられる｡
頭から終わりまでバラエティに富んだ1枚となっており､なんといっても最後の『Dearest Love』が…ええな｡
6曲目の『The Fourth Avenue Cafe』といえばるろ剣ですが､『Dearest Love』を聴いて勝手に星霜編を思い出して勝手に気分がよくなってしまう｡
9曲目の『I wish』のあたたかい冬感から一転して真冬のような冷たさ(雪国出身並感)が､たまらん

# 3位 The Nightfly - Donald Fagen

{% twicard "" https://www.youtube.com/watch?v=Ueivjr3f8xg&list=OLAK5uy_kJmuqJb6DRctnv0NEBJNkhfwy8aSqrYA8&index=2 %}

カッコ良すぎる…｡
かっこいい音をちゃんと配置するとこうなるかのような完成度｡
中でも1曲目の『I.G.Y.』がやはり至高…イントロかっこよすぎだろ｡これを聴きながら都会の夜を歩きたすぎだろ｡

# 2位 Metropolis Part 2: Scene from a memory - Dream Theater

{% twicard "" https://www.youtube.com/watch?v=H2UHWFU5uFY&list=OLAK5uy_mY0UJ7SdDG7n4DgXGJ_h-vG0QH9LpayaA %}

高校の修学旅行の自由時間でCDショップに行き即ホテルに戻ってこのアルバムを聴きながらベッドで涙を流しつつ就寝た思い出の一枚｡
同室だった相馬くんはDinosaur Jr.を聴いていた｡

コンセプトアルバムの最高峰｡
アルバムを再生すると物語を追体験することになる｡
1､2曲目の物語に吸い込まれていくようなイントロダクションから『Strange Deja Vu』の結末を予告するような少し切ないのに爽やかな勢いの乗ったサビが､すごーい…
そのまま物語が怒涛のDream Theaterワールドの上で展開して映画のラストシーンのようなクライマックスの『Finally Free』に至り､茫然自失となる｡
この物語の1つ前にあたる『Metropolis Part 1: The Miracle and the Sleeper』もすごい｡
すごいっつうか意味わからん｡

# 1位 カレンダーガール - わか･ふうり･すなお

{% twicard "" https://www.youtube.com/watch?v=B4NhvHuvfTI %}

すまんやけど｡
アイカツ1期ED｡
この一曲には星宮いちごさんが大スター宮になるまでの重みがあってですね｡
グルーヴィなサウンドでABメロノリノリなんだけどサビメロが少し切ない入りで､だけど最後はパッとなる構成｡
しかしてサビの"何てコトない毎日が かけがえないの オトナはそう言うけれど いまいちピンとこないよ"って､なんや…😭
1期にして早くもそれぞれの道を歩んでいくのを予見するようなセツナメロディ､でもそれを跳ね飛ばす元気さや若さ､まだフツーの女の子感｡
俺って元アイドルじゃないんだけど､幼少期に仲良かったけど疎遠になった友達や何者でもないバカガキで遊んでいた頃を思い出さずにはいられない｡
そしてまさに宝ものになるなんてことない毎日を駆け抜けている(た)彼女たちが歌うんだよね､"いまいちピンとこないよ"って｡
"思い出は未来のなかに"ってなんですかあおいさん?! 情緒がおかしくなっちまうよ…｡
